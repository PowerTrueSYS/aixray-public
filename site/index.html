What AIXray answers

Where does this AIX or VIOS system actually stand?

AIXray reads observable posture across lifecycle, patching, storage, performance, errors, resilience, security, configuration, and monitoring. It reports the evidence; it does not repair the host.

01 / BOUNDARY

Read-only

System configuration is inspected, never remediated. Requested report paths are the operator-controlled output.

02 / EGRESS

Zero network calls

Assessment execution does not fetch reference data or transmit report data.

03 / RUNTIME

Single ksh88 file

Runs with AIX `/bin/sh`; no bash, Python, GNU userland, or package install required.

04 / HONESTY

No fabricated status

Unavailable or ambiguous evidence can be `NOT_ASSESSED`; it is not silently reported as a pass.
