## Is AIXray open source?

No. Its source is available for inspection, but PolyForm Internal Use is not an OSI-approved open-source license. Describe AIXray as **source-available** or **licensed for internal use**, not as open source.

## Why might GitHub show an unbadged “View license” link?

GitHub’s named license badge depends on its license-detection catalog. PolyForm Internal Use is not currently represented by an SPDX License List identifier that GitHub can display as a standard named badge. GitHub may therefore provide an unbadged “View license” link instead. That is a presentation detail; it does not weaken or change the terms in `LICENSE`.

## What identifier should machines use?

Use the SPDX custom-license-reference form:

```text
LicenseRef-PolyForm-Internal-Use-1.0.0
```

`LicenseRef-PolyForm-Internal-Use-1.0.0` is not an SPDX License List identifier. It is the project’s machine-readable reference to the exact PolyForm text in `LICENSE`. The public manifests and `catalog.json` use this value.
